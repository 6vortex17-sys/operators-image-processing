# Image Processing Operators — Kernel Lab

A GitHub Pages presentation site for the `Copy_of_operators.ipynb` image-processing project.

## Included
- Sobel edge detection
- Prewitt edge detection
- Laplacian edge detection
- Kernel visualizations
- Browser-based image upload and live edge-detection demo
- Link to the original Python/Google Colab notebook

## GitHub Pages
The site is a static `index.html` site, so it can be published directly from the repository root. GitHub Pages uses `index.html` as an entry file. See the official GitHub Pages documentation for publishing-source configuration.

## Local preview
Open `index.html` in a browser. No build step is required.
